# React JSX 실습

## 시작하기

**프로젝트 생성**
```bash
- Project Name : 프로젝트명
- Framework : React
- Variant : JavaScript
- Linter : ESLint
```

**프로젝트 실행**
```bash
npm install     # 최초 1회
npm run dev     # 실행 위치 => 프로젝트 루트 경로 (package.json 파일이 존재해야 함)
```

**문법 오류 확인(테스트)**
```bash
npm run lint
```

**프로젝트 실행 종료**
`ctrl` + `C` => 종료하시겠습니까? `Y` 입력
